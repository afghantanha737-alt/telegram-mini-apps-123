# Gramup — مینی‌اپ تلگرام

مینی‌اپ تلگرام برای جمع‌آوری پوینت (تسک، ورود روزانه، گردونه، دعوت دوستان)، تبدیل پوینت به GRAM و درخواست برداشت.
بک‌اند: Node.js + Express + MongoDB. فرانت‌اند: HTML/CSS/JS ساده در `public/` (سه زبان: دری، پشتو، انگلیسی).

## راه‌اندازی

```bash
npm install
cp .env.example .env     # و مقدارها را پر کنید (حداقل BOT_TOKEN، MONGO_URI، ADMIN_KEY)
npm start
```

پنل ادمین: `https://آدرس-شما/admin.html` (با `ADMIN_KEY` وارد می‌شود).

## قابلیت‌های مهم

- **عضویت اجباری در کانال‌ها:** در پنل ادمین، تب «کانال‌های اجباری». ربات باید در کانال **ادمین** باشد.
  عضویت هر بار که مینی‌اپ باز می‌شود دوباره از تلگرام (`getChatMember`) بررسی می‌شود و همه‌ی APIهای محافظت‌شده هم آن را چک می‌کنند.
  اگر بررسی ممکن نباشد، کاربر تایید نمی‌شود (fail-closed).
- **گردونه:** شانس رایگان با استریک ۷ روزه، یا چرخش با پوینت (هزینه و درصد شانس از پنل ادمین → تنظیمات).
  سرور اجازه نمی‌دهد تنظیماتی ذخیره شود که چرخش پولی را برای کاربر سودآور کند.
- **برداشت:** همیشه دستی توسط ادمین بررسی و تایید می‌شود.

## تست‌ها

```bash
node tests/membership.test.js   # منطق عضویت اجباری
node tests/spin.test.js         # بازده‌ی گردونه‌ی پولی و اعتبارسنجی تنظیمات
```

## ساختار پوشه‌ها

| مسیر | توضیح |
|---|---|
| `server.js` | راه‌اندازی Express، middlewareها، مسیرها |
| `routes/` | APIها (auth، tasks، points، referral، leaderboard، membership، admin، telegramWebhook) |
| `models/` | مدل‌های Mongoose |
| `utils/` | احراز هویت تلگرام، ربات، منطق عضویت (`membershipCore.js`)، گردونه (`spin.js`) و ... |
| `public/` | مینی‌اپ (`index.html`, `js/`, `css/`) و پنل ادمین (`admin.html`) |
| `tests/` | تست‌های منطق سرور (بدون نیاز به دیتابیس) |
