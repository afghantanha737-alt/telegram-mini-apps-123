# 🚀 Amir Crypto Hub Mini App

پروژه Telegram Mini App برای ربات **@AmirAFG123_bot**

## ✨ ویژگی‌ها

- 🎨 **ظاهر مدرن و حرفه‌ای** - UI/UX بهینه‌شده برای موبایل
- 🎯 **سیستم تسک‌ها** - انجام تسک‌ها و دریافت امتیاز
- 👥 **سیستم Referral** - دعوت دوستان و کسب امتیاز
- ⭐ **مدیریت امتیازات** - ردیابی امتیاز و آماری
- 🔐 **بررسی عضویت** - چک کردن عضویت در کانال با Telegram API
- 📊 **پایگاه داده** - ذخیره‌سازی داده‌های کاربران

## 📋 متطلبات

- Python 3.8+
- Telegram Bot Token
- Flask 3.0+
- SQLite3
